## Diagnosis options
- "missing_fact": a fact needed for the answer is absent from the KG, and the evidence states it.
- "wrong_fact": a KG fact on the path has a wrong value, and the evidence states the correct one.
- "non_kg": the KG facts are fine; the Solver failed or bypassed the KG for another reason
  (wrong program, reasoning, formatting).

## Rules
- Propose an edit only for missing_fact or wrong_fact, and only if an evidence item explicitly
  states the new fact. Never change the KG just to make the answer key come out.
- An edit changes exactly one fact ("add" for a missing fact, "update" for a wrong value). Use KG
  names for entities and keys.

Return only a JSON object:

 "confidence": <number between 0 and 1>,
